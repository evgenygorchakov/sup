# test

Два уровня проверок, от самого дешёвого к самому дорогому. Уровень — это верхний каталог,
фича — файл внутри него.

| Уровень | Что запускается по-настоящему | Чем запускать | Сколько идёт |
| --- | --- | --- | --- |
| `unit/` | только модуль, никаких провайдеров и терминала | `node test/run.ts` | секунды |
| `stub/` | настоящий цикл хода `src/agent.ts` на провайдере-заглушке | `node test/run.ts` | секунды |

```
test/
  run.ts               node test/run.ts [фильтр]   — уровни unit/ и stub/
  lib/check.ts         общий check()/done() для node-проверок
  unit/plan.ts                 \
  unit/thinking.ts              \
  stub/plan-turn.ts              > проверки, названные по фиче
  stub/plan-journal.ts          /
  stub/plan-investigation.ts   /
  bench/               замеры, а не проверки: запускаются руками, ходят в сеть и к модели
  logs/                вывод замеров, который стоило сохранить
```

Проверка называется по своему пути: `test/unit/plan.ts` — это `unit/plan`. Этим же именем
работает фильтр (`node test/run.ts plan`).

Новая фича добавляется двумя файлами на тех же местах: `unit/<фича>.ts` и `stub/<фича>-*.ts`.
Раннер находит их сам, регистрировать нигде не нужно.

## node-проверки

```
node test/run.ts                # всё
node test/run.ts plan           # только те, в чьё имя входит аргумент
node test/run.ts --list         # что вообще есть
node test/unit/plan.ts          # один файл, напрямую
```

Каждый файл — отдельный процесс: они делают `chdir` и правят `process.env` до импорта `src`,
так что в одном процессе им не ужиться. Внутри — `check(имя, факт, ожидание)` из `lib/check.ts`
и `done()` в конце; код возврата и есть вердикт.

## Замеры

`bench/` — не проверки: у них нет вердикта, они печатают числа, по которым выбирается настройка.
Каждый файл запускается руками и ходит наружу — `fetch-pages.ts` и `extraction-gaps.ts` за
реальными страницами, `search-results.ts` в поисковый провайдер, `sampling.ts` прямо в
`/api/chat` с `OLLAMA_HOST` и `MODEL` из `.env`. Как запускать — в шапке самого файла.
